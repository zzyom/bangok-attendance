# 반곡고 2학년 미인정 출결

2학년 9개 학급의 3~12월 미인정 결석·조퇴·결과·지각 횟수를 월별로 입력하고, 3월부터 누적해 환산 결석을 계산하는 웹앱입니다.

- 화면: GitHub Pages (이 저장소의 `index.html`)
- 데이터: Firebase Firestore
- 로그인: Firebase Authentication 공용 계정 2개 (선생님용, 학년부장용)

## 계산 규칙

```
환산 결석 = 미인정 결석 + ⌊(미인정 조퇴 + 미인정 결과 + 미인정 지각) ÷ 2⌋
```

3월부터 항목별로 먼저 더한 뒤 위 식을 적용합니다.

| 조건 | 상태 |
|---|---|
| 환산 결석 6회 이상 | 대상 |
| 미인정 기록 1건 이상, 환산 5회 이하 | 주의 |
| 기록 없음 | 정상 |

## 권한

| 계정 | 할 수 있는 일 |
|---|---|
| 선생님 (`teacher@…`) | 모든 학급 조회·입력. 마감된 달은 수정 불가 |
| 학년부장 (`admin@…`) | 위 내용 + 월 마감·해제, 마감된 달 수정, 백업, 자료 가져오기(명렬 변경) |

마감은 `firestore.rules`에서도 막으므로 앱을 거치지 않고도 고칠 수 없습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 스타일 |
| `app.js` | 동작 (Firebase 연동, 계산) |
| `firebase-config.js` | Firebase 프로젝트 값, 공용 계정 이메일 |
| `firestore.rules` | Firestore 보안 규칙 (콘솔에 붙여 넣음) |

## 데이터 구조 (Firestore)

| 컬렉션 | 문서 id | 내용 |
|---|---|---|
| `roster` | `2-1` ~ `2-9` | `{cls, teacher, students:[{no, name, gender, status, leftDate?, leftMonth?}]}` |
| `records` | `2-3_10` (학급_월) | `{cls, month, rows:{번호:[결석, 조퇴, 결과, 지각]}, savedBy, savedAt}` |
| `locks` | `3` ~ `12` | `{locked, by, at}` |

## 학생 개인정보

이 저장소는 공개입니다. **명렬, 백업 JSON, CSV를 절대 커밋하지 마세요.** `.gitignore`가 `*.json`, `*.csv`, `*.xlsx`를 막고 있습니다.
명렬을 바꿀 때는 학년부장 계정으로 로그인해 입력 현황판 아래 **관리자 도구 → 자료 가져오기**로 JSON 파일을 올립니다.

## 운영 팁

- 매달 마감 후 **관리자 도구 → 전체 백업**으로 JSON을 받아 학교 드라이브에 보관하세요.
- 비밀번호를 바꾸려면 Firebase 콘솔 → Authentication → 사용자에서 해당 계정의 비밀번호를 재설정합니다.
- 새 학년도에는 Firestore의 `records`, `locks`를 백업 후 비우고 새 명렬을 가져옵니다.
